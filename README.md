# Calendar Demo（可変日数カレンダー・デモ版）
<br>
<br>
アクセスした月の日数に合わせてマス数が自動で変わる、シンプルなカレンダー／日めくりデモWebアプリです。
<br>
外部ライブラリやバックエンドは使わず、HTML / CSS / JavaScript のみで構成しています。
<br>
<br>

## 概要
<br>
- アクセスした「年・月」の末日（28〜31日）を自動取得し、1日〜末日までのマスを生成します。
<br>
- 基準日より未来の日付マスはロックされ、当日から過去の日付マスを開封できます。
<br>
- 閲覧者が機能をすぐ試せるよう、画面上から基準日を擬似変更できるデモ機能を備えています。
<br>
<br>

## 主な機能
<br>
- **月別日数の自動生成**: 28日・30日・31日の月に合わせてグリッド表示を自動調整
<br>
- **開封ロック＆状態保存**: 基準日より先の日付は未解放扱いとし、開封済みデータはブラウザの `localStorage` に保存
<br>
- **擬似日付切り替え（デモ用）**: 任意の日付を選択して、その日時点の解放状態や表示を確認可能
<br>
- **日替わりメッセージ表示**: 日付に応じたテキストをモーダルで表示
<br>
<br>

## 構成・技術スタック
<br>
- **HTML / CSS / JavaScript**（外部ライブラリなし、単一ファイル構成）
<br>
- **状態管理**: `localStorage`（サーバー・外部データベース不使用）
<br>
<br>

## 使い方
<br>
1. ブラウザで `index.html` を開く（またはホスティング先URLにアクセスする）
<br>
2. 解放されている日付マスをクリックしてメッセージを確認
<br>
3. 未来の日付や月末の挙動を試したい場合は、上部の日付選択から基準日を変更
